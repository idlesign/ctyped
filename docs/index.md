# ctyped

<https://github.com/idlesign/ctyped>

## Description

*Build ctypes interfaces for shared libraries with type hinting*

**Requires Python 3.10+**

* Less boilerplate;
* Logical structuring;
* Basic code generator (.so function -> ctyped function);
* Useful helpers.

## Requirements

1. Python 3.10+
